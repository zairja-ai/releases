# Zairja releases

Downloads for invited testers of **Zairja**: the engine binaries, the
desktop app, and the SDK packages. Every artifact is listed under
[Releases](https://github.com/zairja-ai/releases/releases), with its SHA-256
checksum.

This repository holds **release artifacts only**; the source is not published here.

- **Getting started:** the Quickstart in Zairja Studio (Docs → Get started).
  Access is invite-only.
- **Verify a download:** `shasum -a 256 <file>` should match the `SHA256SUMS`
  file attached to the release.
- **Licence and terms:** the licence and tester terms come with each release
  and with your invite. Please read them before using Zairja in production.
